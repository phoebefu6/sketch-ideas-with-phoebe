What the guard never reads
toolUse.input · toolResult · toolSpec
Bedrock content filters and sensitive-information filters both skip all three. PII in a tool call is neither blocked nor masked.
Why the API had to exist
InvokeGuardrailChecks, June 2026. Resource-less, score-only, and you must call it - before the tool runs.
The mirror trap
OpenAI Agents SDK fires input guards only for the first agent and output guards only for the last. Every handoff between them is bare.
Best open guard, assayed
69% recall · 11% FPR
Llama Guard 4, English. Three in ten unsafe items pass unseen, and one in nine safe ones is refused. Multilingual recall falls to 43%.
Where to wire it
Validate tool arguments before execution and tool results before they re-enter context. Least-privilege scopes. Human approval on anything irreversible.
