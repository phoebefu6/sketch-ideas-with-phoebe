# LinkedIn caption draft - bus factor comic

Every company has a Sam.

Sam is lovely. Sam is helpful. Sam is also the only person who knows how the pricing system works.

Engineers have a name for this: the bus factor - the number of people who can leave before a system stops. Not servers. People.

I've watched this play out more than once. The system never breaks on the day Sam leaves. It breaks three weeks later, on the first exception Sam used to handle from memory.

If the answer to "who else can run this?" is nobody, you don't have a system - you have a favour.

Three ways to raise your bus factor, none of them glamorous:
- Document while Sam is still here (not during the exit interview)
- Pair a second person on every critical system
- Rotate ownership so knowledge never settles in one head

Count yours this week. Route by route.
