Worth a Thousand Words / Data Portrait No. 03
Stateless Replay / SV-034 Two-Color Acid

You sent 40 turns.
The API billed 820.

One conversation, drawn as the bill instead of the chat

Why it compounds

The Messages API is stateless. Nothing is remembered, so every request carries the whole conversation again: request 40 re-sends the 39 turns before it.

N requests bill T(N) = N(N+1)/2.

The multiplier is (N+1)/2 - worst exactly when the chat is going well.

What it costs

ILLUSTRATIVE - USE YOUR OWN NUMBER:

at 1,000 tokens a turn, 820 blocks are 820,000 input tokens - USD 4.10 on Claude Opus 5 at 5.00 per MTok.

Per-turn math predicts 40,000 tokens and 20 cents. Same chat, 20.5x the bill - and output is billed on top.

The fix

Caching re-prices the replay, it does not stop it: a cache hit bills 0.1x base input (50 cents per MTok on Opus 5), each new block still costs a 1.25x write, and the cache lives five minutes by default.

So cap the history you send, and summarise old turns.

Sources: platform.claude.com/docs - Messages API ("stateless multi-turn conversations", prior turns supplied by the caller) and Pricing (Claude Opus 5 base input USD 5.00 per MTok, cache hit USD 0.50 per MTok = 0.1x, 5-minute cache write 1.25x), fetched 2026-09-07. T(40) = 820 is arithmetic, not an estimate.
