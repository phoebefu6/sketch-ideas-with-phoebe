# The accuracy mask

## Key Concept

A model can look validated while being validated on nothing meaningful. The impressive number becomes a public face, but the evidence behind it is empty.

## Explanation

The green `97%` mask is the board-ready version of the model: polished, confident, and easy to applaud. The torn-open side reveals what the metric is made from - blank placeholder cards instead of real validation records.

The point is not that accuracy is bad. The point is that accuracy is only as honest as the test set behind it. Before celebrating a model score, ask what was validated, against what data, and whether that data represents the decision you are about to make.
